Detection

Compares audio fingerprints across episodes of the same season to find a repeated intro/credits sequence.
Imports a Comskip .edl file next to the media if one exists. Enable the heuristic fallback below to also scan files with no .edl.
Slower and much less reliable than Comskip. Recommended: run Comskip separately and leave this off unless you have no other option.

Intro/Outro tuning

How much of the start and end of each episode is fingerprinted and compared.
Lower is stricter. Raise this if real intros are being missed; lower it if unrelated audio is being matched.
